## Selected work

### ArchiFlow

An AI workspace for architecture diagrams and design reviews. The frontend is a React and Vite chat UI with React Flow, Mermaid, and charts. The backend is a FastAPI service with a DeepSeek agent and a vendored Archify CLI.

[Frontend](https://github.com/sai5880/archiflow-frontend) | [Backend](https://github.com/sai5880/archiflow-backend)

### Quad-C

Agentic US mortgage document verification. FastAPI and React labeling studio, per-document JSONB tables, AI agents for the four Cs, and a single-container deployment.

[Repository](https://github.com/sai5880/quad-c)

### AI Support Triage Agent

Multi-domain support triage for HackerRank, Claude, and Visa. Uses RAG with Gemini, GLM, and Claude to resolve tickets across different product domains.

[Repository](https://github.com/sai5880/ai-support-triage-agent)

### Damage Claim Verification

Multimodal evidence review with vision-language models. Verifies damage claims from images, conversations, and user history, with 75 percent accuracy on claim status prediction.

[Repository](https://github.com/sai5880/damage-claim-verification-system)

### Teams Chat Exporter

Exports Microsoft Teams Free and personal chats and group chats to JSON and CSV. Built because Microsoft Graph does not support personal accounts for this use case.

[Repository](https://github.com/sai5880/teams-chat-exporter)

### LLM FT Release Lib

A fine-tuned 2B LLM for ML library Q&A and code generation. Runs locally through GGUF quantization.

[Repository](https://github.com/sai5880/llm-ft-release-lib)
